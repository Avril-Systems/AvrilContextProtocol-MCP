# ADR-001 — Launcher Before Company OS

**Status:** CURRENT  
**Date:** 2026-10-05  
**Decision type:** Product strategy

## Context

Avril currently has a commercial Launcher / Lab path, provisioning infrastructure in LaunchOpenClaw, and a separate Dashboard that already prototypes Company OS-shaped functionality.

The reality audit found that the Dashboard has moved ahead into Stage 3–4 concepts while Stage 1 evidence is still incomplete.

## Decision

Avril's current commercial priority is the **Agent Launcher / Lab**.

The Dashboard remains an **experimental implementation of the Agentic Company OS thesis**.

New Company OS functionality should not become the primary commercial focus until Stage 1 is proven.

## Stage 1 proof

- real payment
- real provisioning
- persistent ready agent
- actual usage
- repeat usage
- acceptable operational reliability

## Current hierarchy

1. Agent Launcher / Lab — current product
2. LaunchOpenClaw — current provisioning infrastructure
3. Avril Dashboard — experimental Company OS prototype
4. Agentic Company OS — long-term product thesis

## Non-decision

This ADR does **not** decide whether the Dashboard should eventually use LaunchOpenClaw as its runtime.
