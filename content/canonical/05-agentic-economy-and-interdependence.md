# Agentic Economy and Interdependence

**Status:** RESEARCH / THESIS  
**Scope:** Ecosystem model  
**Last updated:** 2026-10-02

## Core idea

A useful agentic economy is not simply agents paying other agents in a closed loop.

External value must enter the system.

At least some companies must solve problems for which humans, businesses, or other economically funded systems are willing to pay.

## Interdependent companies

An agentic company can be both:

- consumer of services
- provider of services

Example:

A research company may buy:

- inference
- context retrieval
- web data
- browser execution

and sell:

- structured intelligence
- reports
- market monitoring
- machine-readable research

A context company may buy:

- compute
- embeddings
- storage

and sell:

- retrieval
- packing
- memory
- context routing

This produces software supply chains between companies.

## Service layers

Potential machine-consumable service categories include:

### Inference
Examples:
- model routing
- specialized inference

- privacy-preserving inference

### Context
Examples:
- retrieval
- context packing
- memory
- context routing
- shared company state

### Tools / MCP
Examples:
- private MCP tools
- premium capabilities
- company-specific connectors
- access-controlled workflows

### Data
Examples:

- real-time feeds
- web extraction
- vertical APIs

### Execution
Examples:
- browser runtime
- code runtime
- workflow execution
- background jobs

### Identity / Permissions
Examples:
- agent identity
- credential access
- role policies
- approvals

### Human services
Examples:
- KYC
- account creation
- physical actions
- legal signatures
- expert review

## The Avril position

Avril does not need to own every service layer.

Its role may be to compose them into a working company.

The launcher gives Avril visibility into which dependencies become unavoidable across many deployments.

Those repeated dependencies may later become products.
